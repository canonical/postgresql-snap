# PostgreSQL snap 18.6

The [PostgreSQL snap](https://snapcraft.io/postgresql) 18.6 was released to the `18/stable`
channel on 5 October 2026.
It is built on the `core26` base (Ubuntu 26.04 LTS) and ships PostgreSQL 18.6.

This is the first stable release in the 18 track.
For changes in PostgreSQL itself, see the upstream
[PostgreSQL 18.6 release notes](https://www.postgresql.org/docs/release/18.6/).

This release introduces PostgreSQL 18 as a strictly confined snap. On install, the snap creates a
default `main` cluster, which runs as the `postgresql.postgresql` service. Like the latest releases
in the 16 track, it lets client commands connect to servers over the network and avoids AppArmor
denials for `oom_score_adj` in the kernel log.

Unlike the 16 track, the snap doesn't expose the `postgresql-common` cluster wrappers
`postgresql.createcluster`, `postgresql.ctlcluster`, `postgresql.dropcluster`,
`postgresql.lsclusters` and `postgresql.renamecluster`. It also doesn't include JIT compilation,
which the Ubuntu `postgresql-18` package installs by default through `postgresql-18-jit`.

Refreshes that would change the PostgreSQL major version are aborted, and snapd rolls back to the
previous revision, so an existing 16 installation can't be refreshed to the 18 track. To migrate,
export the data with `postgresql.dumpall --globals-only` and `postgresql.dump`, then restore it
with PostgreSQL 18.

## Downloads

Install the latest revision of the `18/stable` channel from the
[Snap Store](https://snapcraft.io/postgresql):

```shell
sudo snap install postgresql --channel=18/stable
```

To install a particular revision of the 18 track:

```shell
sudo snap install postgresql --channel=18/stable --revision=<revision>
```

To update an existing installation of the 18 track to a particular revision:

```shell
sudo snap refresh postgresql --channel=18/stable --revision=<revision>
```
