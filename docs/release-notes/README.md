# Release notes

Release notes for stable releases of the PostgreSQL snap, one file per version:
`<track>/<version>.md`.

Drafts are generated by [`generate.py`](generate.py) from the
[`template.md.j2`](template.md.j2) template, then reviewed and edited manually.

## Generate a draft

1. Add the release to `releases.toml` in this directory.
   This file is local only (git-ignored); take the data from the Snap Store
   release history:

   ```toml
   [[release]]
   track = "16"
   version = "16.15"
   date = 2026-10-05                         # released to <track>/stable
   revisions = { amd64 = 270, arm64 = 268 }
   # since = "<git ref>"                     # only for the first release in a track
   ```

2. Run the generator with [uv](https://docs.astral.sh/uv/)
   (or `python3` with `jinja2` installed):

   ```shell
   uv run docs/release-notes/generate.py 16 -o docs/release-notes/16/16.15.md
   ```

   The version is optional and defaults to the latest one in the track.
   Without `-o`, the draft is printed to stdout.

The generator uses the GitHub API with a token from `GITHUB_TOKEN` or
`gh auth token`, and the Launchpad API for the Ubuntu package version.

## How changes are collected

* The changes are the commits between the `rev<N>` tag of the previous release
  in the track (or `since`) and the tag of this release.
* Several stable releases of the same version are combined into one: the latest
  revisions are used, and changes are listed since the previous version.
* Merged PRs are sorted into sections by label: `enhancement` → Features,
  `bug` → Bug fixes, anything else → Other improvements.

## Review a draft

* Write the highlights in the intro, replacing the `TODO` comment.
* Move items between sections, reword or drop noise (for example, dependency
  bumps), and remove empty sections.

For a first pass with an AI agent, attach [`review-prompt.md`](review-prompt.md)
and the draft to the chat, then check the agent's edits and report.
