# PostgreSQL snap 16.11

The [PostgreSQL snap](https://snapcraft.io/postgresql) 16.11 was released to `16/stable` on
9 December 2025. Built on `core24` (Ubuntu 24.04 LTS), it updates PostgreSQL from 16.10 to 16.11.
See the upstream [PostgreSQL 16.11 release notes](https://www.postgresql.org/docs/release/16.11/).

The PostgreSQL update fixes two security issues: missing schema `CREATE` privilege checks in
`CREATE STATISTICS` (CVE-2025-12817) and integer overflows in libpq allocation-size calculations
(CVE-2025-12818), along with a variety of other upstream bugs. Upstream doesn't require a dump
and restore for this update.

The other changes maintain the CI workflows and test dependencies, and add a security policy to
the repository that describes how to report vulnerabilities.

## Downloads

Install the latest revision of the `16/stable` channel from the
[Snap Store](https://snapcraft.io/postgresql):

```shell
sudo snap install postgresql --channel=16/stable
```

To install a particular revision of the 16 track:

```shell
sudo snap install postgresql --channel=16/stable --revision=<revision>
```

To update an existing installation of the 16 track to a particular revision:

```shell
sudo snap refresh postgresql --channel=16/stable --revision=<revision>
```
