# PostgreSQL snap 16.14

The [PostgreSQL snap](https://snapcraft.io/postgresql) 16.14 was released to the `16/stable`
channel on 25 May 2026.
It is built on the `core24` base (Ubuntu 24.04 LTS) and ships PostgreSQL 16.14.

This release updates PostgreSQL from 16.13 to 16.14.
For changes in PostgreSQL itself, see the upstream
[PostgreSQL 16.14 release notes](https://www.postgresql.org/docs/release/16.14/).

The PostgreSQL update brings upstream security fixes, so updating is recommended.

The `postgresql.basebackup`, `postgresql.isready`, `postgresql.pgbench`, `postgresql.receivewal`
and `postgresql.recvlogical` commands can now connect to servers over the network, which strict
confinement blocked before. The snap also publishes more metadata in the Snap Store, such as its
contact, license and links to the source code and issue tracker.

## Downloads

Install the latest revision of the `16/stable` channel from the
[Snap Store](https://snapcraft.io/postgresql):

```shell
sudo snap install postgresql --channel=16/stable
```

To install a particular revision of the 16 track:

```shell
sudo snap install postgresql --channel=16/stable --revision=<revision>
```

To update an existing installation of the 16 track to a particular revision:

```shell
sudo snap refresh postgresql --channel=16/stable --revision=<revision>
```
