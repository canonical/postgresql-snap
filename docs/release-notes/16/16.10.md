# PostgreSQL snap 16.10

The [PostgreSQL snap](https://snapcraft.io/postgresql) 16.10 was released to the `16/stable`
channel on 8 October 2025.
It is built on the `core24` base (Ubuntu 24.04 LTS) and ships PostgreSQL 16.10.

This release updates PostgreSQL from 16.9 to 16.10.
For changes in PostgreSQL itself, see the upstream
[PostgreSQL 16.10 release notes](https://www.postgresql.org/docs/release/16.10/).

## Downloads

Install the latest revision of the `16/stable` channel from the
[Snap Store](https://snapcraft.io/postgresql):

```shell
sudo snap install postgresql --channel=16/stable
```

To install a particular revision of the 16 track:

```shell
sudo snap install postgresql --channel=16/stable --revision=<revision>
```

To update an existing installation of the 16 track to a particular revision:

```shell
sudo snap refresh postgresql --channel=16/stable --revision=<revision>
```

[GitHub](https://github.com/canonical/postgresql-snap/).
