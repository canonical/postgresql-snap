# PostgreSQL snap 16.10

The [PostgreSQL snap](https://snapcraft.io/postgresql) 16.10 was released to `16/stable` on
8 October 2025. Built on `core24` (Ubuntu 24.04 LTS), it updates PostgreSQL from 16.9 to 16.10.
See the upstream [PostgreSQL 16.10 release notes](https://www.postgresql.org/docs/release/16.10/).

The PostgreSQL update brings upstream fixes for three security vulnerabilities and many other
bugs. Among them is a fix for BRIN indexes with the `numeric_minmax_multi_ops` operator class;
for existing indexes of this type, see [Migration to
Version 16.10](https://www.postgresql.org/docs/16/release-16-10.html#RELEASE-16-10-MIGRATION).

Other snaps can now use PostgreSQL from this snap without bundling their own copy: the new
`postgresql` content slot gives connected snaps read-only access to the files of this snap,
which is especially useful on Ubuntu Core.

The snap documentation, such as the commands reference and the storage management guide, moved
from Discourse into the [`docs/`](https://github.com/canonical/postgresql-snap/tree/16/edge/docs)
folder of the snap repository, so it is now versioned together with the snap.

## Downloads

Install the latest revision of the `16/stable` channel from the
[Snap Store](https://snapcraft.io/postgresql):

```shell
sudo snap install postgresql --channel=16/stable
```

To install a particular revision of the 16 track:

```shell
sudo snap install postgresql --channel=16/stable --revision=<revision>
```

To update an existing installation of the 16 track to a particular revision:

```shell
sudo snap refresh postgresql --channel=16/stable --revision=<revision>
```

The source code of this release is available on
[GitHub](https://github.com/canonical/postgresql-snap/).
