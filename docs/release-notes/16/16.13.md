# PostgreSQL snap 16.13

The [PostgreSQL snap](https://snapcraft.io/postgresql) 16.13 was released to `16/stable` on
9 March 2026. Built on `core24` (Ubuntu 24.04 LTS), it updates PostgreSQL from 16.11 to 16.13.
See the upstream [PostgreSQL 16.13 release notes](https://www.postgresql.org/docs/release/16.13/).

The only change to the snap itself is the PostgreSQL update. It also includes the changes of the
intermediate PostgreSQL 16.12 release, which fixes several security vulnerabilities, as described
in the upstream [PostgreSQL 16.12 release notes](https://www.postgresql.org/docs/release/16.12/).
Some of these fixes make PostgreSQL stricter: for example, string functions may now report
"invalid byte sequence for encoding" errors for invalid text stored in a database, and attaching
a non-built-in selectivity estimator to an operator now requires superuser privilege.

All other changes maintain the CI workflows, test dependencies and repository settings.
There are no breaking changes to the snap's commands, configuration or paths.

## Downloads

Install the latest revision of the `16/stable` channel from the
[Snap Store](https://snapcraft.io/postgresql):

```shell
sudo snap install postgresql --channel=16/stable
```

To install a particular revision of the 16 track:

```shell
sudo snap install postgresql --channel=16/stable --revision=<revision>
```

To update an existing installation of the 16 track to a particular revision:

```shell
sudo snap refresh postgresql --channel=16/stable --revision=<revision>
```

[GitHub](https://github.com/canonical/postgresql-snap/).
