# PostgreSQL snap 16.13

The [PostgreSQL snap](https://snapcraft.io/postgresql) 16.13 was released to the `16/stable`
channel on 9 March 2026.
It is built on the `core24` base (Ubuntu 24.04 LTS) and ships PostgreSQL 16.13.

This release updates PostgreSQL from 16.11 to 16.13.
For changes in PostgreSQL itself, see the upstream
[PostgreSQL 16.13 release notes](https://www.postgresql.org/docs/release/16.13/).

This is a maintenance release focused on the PostgreSQL update. The update skips PostgreSQL 16.12,
so also check the upstream
[PostgreSQL 16.12 release notes](https://www.postgresql.org/docs/release/16.12/). Other changes are
limited to CI, repository maintenance and development dependencies.

## Downloads

Install the latest revision of the `16/stable` channel from the
[Snap Store](https://snapcraft.io/postgresql):

```shell
sudo snap install postgresql --channel=16/stable
```

To install a particular revision of the 16 track:

```shell
sudo snap install postgresql --channel=16/stable --revision=<revision>
```

To update an existing installation of the 16 track to a particular revision:

```shell
sudo snap refresh postgresql --channel=16/stable --revision=<revision>
```
