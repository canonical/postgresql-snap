# PostgreSQL snap 16.9

The [PostgreSQL snap](https://snapcraft.io/postgresql) 16.9 was released to the `16/stable`
channel on 9 September 2025.
It is built on the `core24` base (Ubuntu 24.04 LTS) and ships PostgreSQL 16.9.

This release updates PostgreSQL from 16.8 to 16.9.
For changes in PostgreSQL itself, see the upstream
[PostgreSQL 16.9 release notes](https://www.postgresql.org/docs/release/16.9/).

This is a maintenance release focused on the PostgreSQL update. The cluster management commands
now use the `install` tool bundled in the snap through a snap layout, which needs fewer changes to
the upstream `postgresql-common` scripts. Other changes are limited to CI and development
dependencies.

## Downloads

Install the latest revision of the `16/stable` channel from the
[Snap Store](https://snapcraft.io/postgresql):

```shell
sudo snap install postgresql --channel=16/stable
```

To install a particular revision of the 16 track:

```shell
sudo snap install postgresql --channel=16/stable --revision=<revision>
```

To update an existing installation of the 16 track to a particular revision:

```shell
sudo snap refresh postgresql --channel=16/stable --revision=<revision>
```
