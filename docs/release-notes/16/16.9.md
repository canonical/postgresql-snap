# PostgreSQL snap 16.9

The [PostgreSQL snap](https://snapcraft.io/postgresql) 16.9 was released to `16/stable` on
9 September 2025. Built on `core24` (Ubuntu 24.04 LTS), it updates PostgreSQL from 16.8 to 16.9.
See the upstream [PostgreSQL 16.9 release notes](https://www.postgresql.org/docs/release/16.9/).

The main change in this release is the PostgreSQL minor update. It doesn't require a dump and
restore, but upstream notes that self-referential foreign keys on partitioned tables and BRIN
bloom indexes might need attention after the update, as described in the upstream
[migration notes](https://www.postgresql.org/docs/16/release-16-9.html#RELEASE-16-9-MIGRATION).

The snap's cluster management tools now use the bundled `install` binary through a bind-mounted
`/usr/bin/install` layout, instead of scripts patched to call a separate `snapped_install` path.
The other changes update CI workflows and development dependencies.

## Downloads

Install the latest revision of the `16/stable` channel from the
[Snap Store](https://snapcraft.io/postgresql):

```shell
sudo snap install postgresql --channel=16/stable
```

To install a particular revision of the 16 track:

```shell
sudo snap install postgresql --channel=16/stable --revision=<revision>
```

To update an existing installation of the 16 track to a particular revision:

```shell
sudo snap refresh postgresql --channel=16/stable --revision=<revision>
```
