# PostgreSQL snap 16.15

The [PostgreSQL snap](https://snapcraft.io/postgresql) 16.15 was released to the `16/stable`
channel on 5 October 2026.
It is built on the `core24` base (Ubuntu 24.04 LTS) and ships PostgreSQL 16.15.

This release updates PostgreSQL from 16.14 to 16.15.
For changes in PostgreSQL itself, see the upstream
[PostgreSQL 16.15 release notes](https://www.postgresql.org/docs/release/16.15/).

**Breaking change:** refreshes that would change the PostgreSQL major version, for example
switching between the 16 and 18 tracks, are now aborted, and snapd rolls back to the previous
revision. A refresh is also aborted if the data directory is missing or holds more than one major
version. To move your data to another major version, see
[Upgrading data via pg_dumpall](https://www.postgresql.org/docs/16/upgrading.html#UPGRADING-VIA-PGDUMPALL)
in the PostgreSQL documentation.

The kernel log is no longer flooded with AppArmor denials for `oom_score_adj` on every new
PostgreSQL process. The new
[OOM tuning](https://github.com/canonical/postgresql-snap/blob/16/edge/docs/oom.md) guide explains
how to protect PostgreSQL from the kernel OOM killer with snapd's `resilience.vitality-hint`.

## Downloads

Install the latest revision of the `16/stable` channel from the
[Snap Store](https://snapcraft.io/postgresql):

```shell
sudo snap install postgresql --channel=16/stable
```

To install a particular revision of the 16 track:

```shell
sudo snap install postgresql --channel=16/stable --revision=<revision>
```

To update an existing installation of the 16 track to a particular revision:

```shell
sudo snap refresh postgresql --channel=16/stable --revision=<revision>
```
