# PostgreSQL snap 16.8

The [PostgreSQL snap](https://snapcraft.io/postgresql) 16.8 was released to `16/stable` on
2 May 2025. Built on `core24` (Ubuntu 24.04 LTS), it is the first stable release in the 16 track.
See the upstream [PostgreSQL 16.8 release notes](https://www.postgresql.org/docs/release/16.8/).

This release introduces PostgreSQL 16 as a strictly confined snap. On install, the snap creates a
default `main` cluster, which runs as the `postgresql.postgresql` service under the `_daemon_`
system user. By default, new clusters trust connections over the local socket and use
SCRAM-SHA-256 password authentication for TCP connections.

The snap follows the cluster layout of the Ubuntu packages and exposes the `postgresql-common`
wrappers as `postgresql.createcluster`, `postgresql.ctlcluster`, `postgresql.dropcluster`,
`postgresql.lsclusters` and `postgresql.renamecluster`. Except for `postgresql.lsclusters`, they
must run as root, and new clusters always use the default data, log and socket locations.
Other tools also drop the `pg_` prefix, for example `postgresql.dump` runs `pg_dump`. Some
`postgresql-common` tools, such as `pg_upgradecluster`, `pg_backupcluster` and
`pg_restorecluster`, aren't included.

## Downloads

Install the latest revision of the `16/stable` channel from the
[Snap Store](https://snapcraft.io/postgresql):

```shell
sudo snap install postgresql --channel=16/stable
```

To install a particular revision of the 16 track:

```shell
sudo snap install postgresql --channel=16/stable --revision=<revision>
```

To update an existing installation of the 16 track to a particular revision:

```shell
sudo snap refresh postgresql --channel=16/stable --revision=<revision>
```
